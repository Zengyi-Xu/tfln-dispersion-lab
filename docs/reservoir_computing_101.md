## 一、一句话版本

蓄水池计算 = **用一个固定的、不复训的非线性动力系统把输入信号喷到高维空间，
只训练最后一层线性读出**。

训练成本从「反向传播几千个参数」变成「解一次最小二乘」。这就是它适合光子的根本原因：
**光学系统很难在线调参，但特别容易造出丰富的非线性动力学**——RC 恰好只需要后者。

---

## 二、为什么需要它（动机）

时序信号处理（语音识别、雷达回波、信道均衡）需要**记忆**：当前输出依赖过去一段输入。
传统方案：

| 方案 | 代价 |
|---|---|
| RNN/LSTM | 训练慢（BPTT）、梯度消失、需要精确可控的权重矩阵 |
| 数字 FIR + MLP | 记忆深度 = 显式抽头数，硬件成本高 |
| **RC** | 不动内部网络，物理系统白送记忆与非线性 |

RC 的三要素（任何物理实现都绕不开）：
1. ** fading memory（渐遗忘性/回声状态性）**：系统对久远输入的影响指数衰减——否则状态爆炸或混沌，不可复现；
2. **足够丰富的内部维度**：不同输入历史映射到可区分的状态；
3. **线性可分的读出**：ridge/LR 即可。

关键定理性质（Jaeger 的 echo state property）：只要环路增益谱半径 < 1（工程口径：ρ 别贴 1 太近），
系统状态由输入历史唯一决定，与初始条件无关——这就是"可复现的物理计算"的数学保证。

## 三、数学框架（够用即可）

### 3.1 ESN（经典形式）

```
x(n+1) = f( W·x(n) + w_in·u(n+1) )      # x∈R^N 隐藏状态
y(n)   = w_out · x(n)                    # 唯一被训练的部分
```

- W 随机稀疏、谱半径 ρ(W) 略小于 1；f 通常 tanh。
- 训练 = 收集状态矩阵 X（T×N），解 w_out = argmin ||Xw − y||² + λ||w||²（岭回归）。
- **从来不动 W** —— 这就是"蓄水池"的名字来源：一池子固定的动力学。

### 3.2 延迟环蓄水池（delay-loop RC）——光子学的主力形态

Appeltant et al., *Science* 2011 的核心洞察：**一个非线性节点 + 一个延迟环 =
一整个 ESN**。把时间当成空间用：

```
环程 τ_loop 切成 N 段，每段 θ = τ_loop/N 称为一个"虚拟节点"
物理节点的响应在环里边走边演化，每隔 θ 采样一次 → N 个虚拟节点的状态
```

我们今晚的仿真用的工程化模型（SCR, Rodan & Tiño 2012 最小复杂度环）：

```
x₀(n+1) = (1−a)·x₀(n) + a·f( ρ·x_{N−1}(n) + γ·u(n) )   ← 注入点（调制器）
x_i(n+1) = x_{i−1}(n)                                  ← 环身（无源延迟）
```

参数与物理量一一对应（这是我们能在 TFLN 上做设计的依据）：

| 参数 | 物理意义 | TFLN 器件上的旋钮 |
|---|---|---|
| N | 虚拟节点数 = τ_loop/θ | 环长 × 采样率 |
| ρ | 环程总增益 | 耦合器分光比 × 环损耗（我们测过 α=0.033 dB/mm → ρ 可算） |
| γ | 输入调制深度 | EO 调制器的驱动电压/Vπ |
| a | 节点惯性 = θ/τ_node | 探测器带宽 vs 符号率 |
| f | 非线性传递函数 | tanh（理想化）vs sin²(·−π/4)（MZM 正交偏置，真实器件） |

> ⚠️ 我们踩过的坑（已写进脚本注释）：Appeltant 原始论文的"逐节点注入随机掩码"
> 离散化模型里，新鲜输入在每个节点注入，旧记忆一个符号周期就被淹没（实测 MC≈1
> 与 ρ 无关）。物理上掩码确实打在输入端，但离散仿真必须用 SCR 这种"单点注入 +
> 无损移位"的形式才能保住记忆。这是文献复现的经典陷阱。

### 3.3 性能度量（今晚扫描的三件套）

- **MC（线性记忆容量）**：驱动随机序列，训练读出去回忆 k 步前的输入，
  MC = Σ_k corr²(û(n−k), u(n−k))。上限 = N。衡量"记忆有多长"。
- **NARMA-10 NMSE**：10 阶非线性自回归系统的仿真误差，衡量"非线性变换有多强"。
  记忆和非线性互相拉扯（线性区记忆好、非线性弱；深饱和反之）——**这个 tradeoff
  地形图就是今晚要画的东西**。
- **场景分类精度**：直接对接我们 M1 的任务（等能量等质心三类 spike 场景，
  真实光栅压缩脉冲），检验物理链端到端可用性。

## 四、为什么 RC 特别适合我们的 TFLN 系统

这是本项目真正的卖点，逐条对：

1. **非线性白送**。MZM 的 sin² 传递函数、探测器的平方律、饱和放大——光子链路里
   非线性躲都躲不掉。RC 把它们变成资源而非误差源。今晚的扫描会直接量化
   "真实 sin² vs 理想 tanh 差多少"。

2. **速度**。光载波 + ps 级符号率，RC 的处理速度就是光速传播。我们 L3 实测压缩脉冲
   0.146 ps、场景窗口 4 ps → 等效符号率几十 GSym/s，电子 RC 望尘莫及。

3. **EO 可调 = 可编程蓄水池**（TFLN 独有）。Pockels 效应让我们能用电信号实时调
   ρ（耦合器）、γ（调制深度）、甚至环的相位——**别人调 W 靠制造，我们靠电压**。
   今晚的地形图扫完，就知道哪些参数值得做成可调的。

4. **慢读出兼容性（已验证的核心结论）**。M1 已证：蓄水池把 ps 级时间图案转成
   节点状态后，**1 ns 漏电积分慢读出精度不降**（C-系列结论：leaky readout 1.000）。
   这把"超快光信号"和"慢速电读出"之间的鸿沟填上了——这是整条链能成立的枢纽。

5. **量化无损（C13，比申报更强）**：2–8 bit 全程无损。RC 的读出对权重精度
   极不敏感（岭回归的冗余度兜底）——对片上 ADC/驱动器是巨大利好。

## 六、怎么把蓄水池做强（改进杠杆，按性价比排序）

### A. 不动硬件，纯算法/协议

1. **读出升级**：岭回归 → 逻辑回归已做；再往上是读出端小 MLP（M7 已证 raw+MLP
   上限 0.663-0.680 这条链中蓄水池是补特征不是主分类器）。
2. **输入编码**（C12 的直接教训）：echo 直方图丢角度 → 把角度信息编码进 spike
   间隔/多通道输入。蓄水池再强也救不了编码丢掉的信息——**编码在前，水池在后**。
3. **多时间尺度读出**：快读出（末态）+ 慢读出（积分）拼接，白送两个尺度的特征
   （今晚场景任务已在用）。
4. **在线学习读出**：递归最小二乘（RLS）替代批量岭回归，适应漂移（温度、老化）。

### B. 器件/架构层

5. **可调 ρ（环程增益）**：地形图扫完后，ρ 大概率是"不同任务不同最优点"——
   EO 可调耦合器让一个芯片服务多任务。**这是 proposal 里最值得写的一句**。
6. **多环级联/深蓄水池**：两个不同 τ_loop 的环串联 ≈ deepESN，记忆与快响应解耦。
   TFLN 低损耗（0.033 dB/mm 保守值，FoM 384–424 ps/dB）使得多环级联的损耗预算可行。
7. **非线性工程**：MZM 偏置点可调 → f 的形状可调；或者故意用探测器的饱和区。
   今晚的 sin2 vs tanh 对比会告诉你非线性"形状"值多少性能。
8. **光栅前端 + 蓄水池联合优化**：目前两段是独立设计的；L3 已打通数据接口
   （真实脉冲 → 场景），下一步可以让光栅的 D/ripple 与蓄水池参数联合寻优。

### C. 理论层

9. **记忆-非线性 tradeoff 的显式建模**：用今晚的地形图拟合 MC(ρ,γ) 与 NMSE(ρ,γ)
   的 Pareto 前沿，写进设计规则（Objective 1 的直接产物）。
10. **噪声的正面利用**：少量注入噪声等价于岭正则（已知结果），低功耗链路里
    噪声不是纯敌人。
