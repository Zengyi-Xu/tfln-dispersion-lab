# 写法建议：光学 MVP（局域场读出）vs 光学能量读出——相关工作段的定位段

> 供零号稿相关工作/讨论段使用（rq 第五十三/五十四批）。这只是写法建议，
> 不改动 `论文零号稿_草稿.md`（11 条更新清单仍待用户拍板）。

## 一句话版本

光子伊辛机的光学核心有两种读出本体论：**能量读出**（SPIM 一系：傅里叶光学
直接测 H=xᵀJx 标量，自旋更新在电子域）与**局域场读出**（我们：模拟域逐自旋
读出 h_i=Σ_j J_ij x_j）。后者正是 spQUBO 论文（NTT，arXiv:2506.24008）明确
承认 SPIM 做不到、并列为未来方向的"光学 MVP"——我们的碰撞调度×共享增益
架构在片上/GHz/免相干条件下实现了它。

## 展开版（可直接化用到论文）

1. **分类学锚点**：McMahon/Shastri/Yamamoto 的百万自旋展望
   （arXiv:2607.13446）把光子伊辛机的耦合实现归为空间/时间/波长复用三类
   MVM——其中波长复用的代表是"微环权重库/交叉阵列"（权重存器件态），
   时间复用是"延迟线+级联 EO 调制"（数字式延迟选通）。**色散群延迟把
   波长差连续映射为时序重叠（碰撞调度）不在该分类学内**——权威综述层面
   格子是空的，这比逐篇先占核查更强的"空白"证据。
2. **能量读出的局限（引 spQUBO 原文）**：SPIM 光学测量的是哈密顿量标量；
   逐自旋局域场（MVP）仍需电子计算——NTT 团队明确将"基于卷积结构的光学
   MVP"列为 future research。能量读出适合做 Monte-Carlo 接受判据，
   但对梯度型/平均场型更新（Hopfield、模拟分岔、CIM 平均场）不够用——
   那些算法需要 h_i 本身。
3. **我们的互补位置**：碰撞调度层（CBG 的 GD 把波长差翻译成到达时序）
   + 共享增益混频层（SOA XGM 载流子共享产生相互作用）在强度域直接读出
   逐自旋局域场——片上、GHz 速率、免相干接收（QUBO 强度编码），
   与 SPIM 的自由空间/SLM/相干能量读出形成互补而非竞争。
4. **诚实边界（防审稿人反打）**：① 我们的耦合是谱距的结构化函数
   （Toeplitz 型），不是任意 J——问题类限于晶格/幂律/距离依赖
   （spQUBO 已论证这类问题有实际价值：布局/聚类）；② 2D 各向同性晶格
   不可行（带宽下界+杂散权衡，rq 第五十一批），诚实表述为"1D 链与
   弱耦合链束"；③ 结构化耦合的数字 FFT 竞争存在（spQUBO 自承）——
   我们的主张落在速率/能效，不落在问题类排他。
