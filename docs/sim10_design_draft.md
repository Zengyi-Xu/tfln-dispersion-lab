## 1. 科学定位（先写死，防止漂移）

两段式架构（digest §五 #8 二次审查结论）：

- **① CBG 碰撞调度层**：线性/分段 GD 把波长差翻译成到达时序差，
  控制哪些自旋脉冲在非线性窗口内相遇（09 正在验证可实现的 J(d) 剖面族）；
- **② 共享增益混频层**：SOA XGM（或共享 OPO 增益竞争）在碰撞时产生
  真实的自旋间相互作用——异色自旋不干涉，耦合只能走载流子共享。

**不与 WDM 全可编程伊辛机（Liu APN 2025 / Luo Sci. Adv. 2023）正面竞争**；
叙事 = "结构化伊辛（晶格/幂律耦合）的天然硬件"（digest §五 #8 定位句）。

**⚠️ 结构化耦合叙事的正式先占（rq 第五十二/五十三批，已全文精读）**：
Yamashita et al. "Spatial QUBO"（arXiv:2506.24008，v2 2026-01，NTT 系）已为
SPIM（自由空间 SLM 伊辛机）明确提出**空间卷积结构 QUBO**——平移不变耦合
作为光子 IM 的天然问题类。全文精读后的精确划界：
① **纯理论**（理想化 SPIM，数值 demo 在 M1 MacBook 上跑动量退火，无实验）；
② SPIM 用透镜傅里叶光学直接光学计算 **H = xᵀJx 标量**（与参考图相关），
   自旋翻转仍在电子域（SLM+图像传感器 OEO 环）；
③ **他们明确承认 SPIM 算不了 MVP（J·x 逐自旋局域场）**，把"基于卷积结构的
   光学 MVP"列为 future research 原文——**而我们的碰撞调度+共享增益架构
   在模拟域读出的恰是逐自旋 h_i = Σ_j J_ij x_j（就是 MVP）**：定位句升级为
   "SPIM 光学读能量、我们光学读局域场——结构化耦合的两条互补光学路线，
   我们是片上/GHz/免相干的那条"；
④ 平移不变/循环矩阵 IM 在他们的 ref 28/29/31 已有空间域先例（2D/3D 近邻
   自旋玻璃、Fourier-mask SPIM）——我们的新性只在**波长域连续 GD 调度**，
   禁止"首个结构化耦合 IM"表述；
⑤ 相干相位编码（他们）vs 强度/QUBO 编码（我们，免相干接收）。

## 2. 编码与动力学模型（digest 三次审查已定的前提）

- **编码**：强度/QUBO，x_i ∈ {0,1} = 脉冲有无，σ_i = 2x_i − 1。
  **禁止相位编码**（异色无干涉，符号信息丢失——三次审查结论）。
- **耦合读取**：共享增益介质内 x_j=1 的脉冲消耗载流子 → 同窗口脉冲 i
  看到的增益被调制，探测器（平方律，强度域）读到的幅度变化正比于
  "邻居点亮数加权和" h_i = Σ_j J_ij x_j——**模拟邻居求和在强度域天然
  成立，无需相干接收**。
- **更新**：光电混合 Hopfield：x(t+1) = Π(h_ext + J·x(t))，
  Π = sigmoid/阈值，电子只做逐点非线性更新（无 MVM、无矩阵存储——
  对照 CMIM 三墙：耦合"存"在 GD 几何+载流子共享里）。

## 3. 唯象混频器模型（本仿真的核心新增件，06 没有）

SOA XGM 唯象模型（参数化，不追求载流子速率方程级精度）：

```
G_i = G_ss / (1 + Σ_j O_ij x_j / P_sat_eff)      # 增益压缩
y_i = x_i · G_i                                   # 脉冲 i 出射幅度
h_i = κ · (G_ss − y_i|_{x_i=1 探测支路})          # 邻居求和读出（差分）
```

- O_ij = 碰撞重叠矩阵，**直接取自 09 的 J(d) 剖面族**（含 GDR 退化版）；
- 关键器件约束（rq 第三十九批 sin 失效区的教训 + COL Ds-PRC 互证）：
  **总输入摆幅 Σ_j O_ij x_j 必须箝在 SOA 增益压缩曲线的单调甜区**——
  建模时设 P_sat_eff 使典型工作点落在压缩区 20–80%，并设"失箝"臂
  （摆幅打进深饱和）复现"非单调折返→失效"的对应现象，验证
  "增益定标是共同纪律"的论断（Ds-PRC 自适应定标 = 该纪律的 SOA 版实例）。

### 5a. 2D 格点→1D 波长轴折叠的解析否决（2026-09-26，rq 第五十一批）

行主序映射 (r,c) → i=r·L+c 下，Toeplitz 核 J(d) 的结构性矛盾：

1. **带宽下界**：任意站点排序都存在边长 ≥L 的格点边（图带宽定理：
   L×L 方格的带宽恰为 L，行主序已达最优）——纵向近邻必然落在
   谱距 d=L 处，无法靠重排消除；
2. **单调核的各向同性-杂散权衡**（高斯核 J(d)=e^(−d²/2w²)，数值表）：
   纵向/横向耦合比 J(L)/J(1) 要到 0.4，需 w≈0.75L，此时杂散/目标
   耦合能量比 ≥4–14（L=8..32）；w 越小杂散越少但 J(L)→0。
   **各向同性与低杂散不可兼得，定量上死刑**；
3. **诚实替代 = 弱耦合 1D 链束**：w≲1.5 时 J(L)≈0，行间自然解耦——
   硬件原生模拟的对象是"多条带多跳短程耦合的 1D 链"（d=2,3 的行内
   耦合正是 09 S3 箱型核目标①，杂散变特性），这是合法且有物理意义的
   模型类（耦合链晶格），不是妥协话术；
4. **翻案条件**：仅当 09 S3 证明分段 GD 能实现支撑集为 {1, L} 的
   梳状非单调核（其余 d 清零），各向同性 2D 才可重议——对啁啾剖面
   要求极高，v1 不指望。
