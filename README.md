- **成图**：notebook 里出草图 → 值得保留的图拿到 [codeplot_v5](file:///D:/kimi_workspace/CAP_NN/codeplot_v5.py) 精修组图（图集存在 `.codeplot_gallery/`）→ 最终论文排版走 [typesetter](file:///D:/kimi_workspace/typesetter)（`.tset`，毫米坐标 + bib）。
