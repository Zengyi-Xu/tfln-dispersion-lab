# sim14-A：CBG 延迟核 × 因果共享增益 —— 因果核提取报告

> 唯象共享增益代理（单ode ḡ=(g0-g)/T_rec-βgΣxⱼpⱼ），**不声称 SOA 器件级复现**；纯 NumPy/SciPy，CPU。梳线 N=32，Δλ=0.2 nm，强度脉冲 FWHM w=10 ps。

## 1. 脉宽口径核对

- 任务书口径：p(t)=exp[-4ln2·((t-τ)/w)²]，w=10 ps **强度 FWHM**；解析重叠 K(Δ)=exp(-2ln2·Δ²/w²)。
- sim09 口径：K(Δ)=exp(-Δ²/(2σ_t²))，σ_t=10 ps （intensity-convolution 约定）。
- 两者**不等价**：w=10 ps 等效 σ_t=6.006 ps（sim09 σ_t=10 等效 FWHM=16.65 ps）。同 σ_t=10 下 sim09 核比任务书核宽 exp(Δ²(2ln2/100-1/200))，Δ=10 ps 处 sim09 值偏宽 142.6%。
- 数值积分与解析 K 最大相对差 2.42e-16（网格收敛）。
- **判定：不支持**「σ_t=10 ps = w=10 ps」的字面等同；后续 J/K 对照全部用任务书 w 口径，sim09 的 σ_t 若迁移需乘 1/0.601。

## 2. 真实 CBG 数据充分性（chirp2d.npz tau_r）

- 谱 121 点覆盖 110.0 nm，平均点距 0.917 nm = 4.58 倍通道间距（0.2 nm）→ 32 通道插值有 ~0.2× 过采样，**点密度足够**。
- 有效反射窗口（R≥0.5·max）：1528.66–1606.85 nm，宽 78.19 nm ≥ 通道足迹 6.20 nm；窗口内 τ_r ∈ [0.13, 3.46] ps，波纹（线性去趋势残差 std）0.289 ps；隔点抽稀重插 RMS 误差 0.175 ps。
- 通道足迹内最小 R = 0.997（max R = 0.999）→ 32 通道全部落在有效反射窗内。
- **判定：支持** 32 通道部署；代价是 τ_r 实测波纹 ~0.29 ps 进入 J （相对 w=10 ps 不可忽略，见下）。

## 4. 数值收敛

- 最差一项：D1.3 dt_half，max|ΔJ|=8.06e-04，|Δε_sym|=3.90e-03。步长减半与窗加倍均在积分噪声以下，**网格收敛**。

## 5. 逐条判定（任务书验收口径）

- **脉宽口径**：不支持 σ_t=w 的字面等同（§1，差异已定量化）。
- **J 对称性**：不支持对称假设 —— 三档群延迟律下 ε_sym 中位数 = 0.579（≠0），因果共享增益给出定向耦合。
- **真实 CBG 是否有足够延迟跨度**：支持 32 通道插值（§2）；但实测 τ_r 波纹 ~0.29 ps 与 D=1.3 ps/nm 档的通道间距 D·Δλ=0.26 ps 同量级，会扰动耦合轮廓 —— 真实数据**可用但有纹波代价**。
- **B 对 NGRC/延迟抽头的净收益**：未决 —— 见 14b 对照（另文）。

## 附：方法与假设

- J 提取（独立线性响应定义）：对每列 j 仿真 g⁽⁰⁾（单泵浦轨迹，可深饱和），探针 ε→0 作被动读出权重，J_ij=∫pᵢ[g⁽⁰⁾−g0]dt —— 主项为 O(β) 直读增益凹陷（因果），探针不进动力学、天然不反饱和。
- 有限探针验证（ε=1e-3 探针进动力学、on/off 差分，对显著元）：小信号档最大相对偏差 2.43e-03（一致）；饱和档 1.26e-01（探针背作用不可忽略，主结果用 ε→0 独立线性响应）。
- 饱和两档：s=β·T_rec=0.05（小信号，单脉冲谷值 g≈0.953）与 5（饱和，g≈0.167）；β=s/T_rec 使两档在不同 T_rec 下可比。
- 时间窗：脉冲跨度 ± max(4w) 对称余量；收敛检验 ×2。
- 唯象声明：本模型是共享增益的**最小因果代理**，不含 SOA 的载流子-光子动力学、ASE、谱烧孔等；器件级结论不外推。
