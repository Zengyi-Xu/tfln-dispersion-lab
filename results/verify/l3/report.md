## 复核结果：**支持（附一条量化修正）**

1. **信号链健壮性：完全支持。** 用实测 `tau_r(λ)` 数值积分重建复反射谱 H(ω)=√R·exp(iφ)，
   单目标匹配滤波得到真实压缩脉冲（FWHM 0.146 ps，带旁瓣/拖尾），替换 `generate_scene`
   的 0.10 ps 解析高斯峰，原协议（等能量等质心三类、40 抽头、漏电慢读出、同种子 2026）重跑：

   | 指标 | 高斯基线（复跑） | 真实脉冲 | 真实脉冲+0.15 阈值 |
   |---|---|---|---|
   | direct（无能耗池） | 0.267 | 0.267 | 0.267 |
   | fast sampling | 1.000 | 1.000 | 1.000 |
   | leaky 慢读出 | 1.000 | 1.000 | 1.000 |
   | linear 消融 | 0.400 | 0.389 | 0.400 |

   高斯基线与 comprehensive_summary.npz 逐位一致（0.267/1.000/1.000/0.400，C17 锚点）。
   真实脉冲（含旁瓣与 2e-6 基底）下四项指标不变 →「高斯 spike」理想化不影响 M1 链结论。
   慢读出保持曲线与抖动扫描（0–0.2 ps）两臂重合，见 `l3_real_chain.png`。

2. **FoM 链：支持，但真实链口径下应报 ≈ 385–390 ps/dB（−8~−10%）。**

   | 口径 | FoM (ps/dB) |
   |---|---|
   | 申报解析值（n_g=2.1，α=33 dB/m） | 424.5 |
   | 解析式代入实测 n_g=2.10457 | 425.5 |
   | 真实信号链（器件级，250 µm：实测平台摆幅 3.21 ps / 传播损耗 0.00825 dB） | **389.1** |
   | 应用级（3 dB 预算，L=9.09 cm，摆幅随 L 缩放，含 R<1 惩罚 0.043 dB） | **383.6**（摆幅 1.167 ns，窗口 0.175 m） |

   偏差来源不是损耗模型，而是 **R>0.9 平台截断效率 η = 3.21/3.51 = 0.915**
   （平台 66.3 nm / 啁啾全程 80 nm 中只有平台段提供可用摆幅）。
   即 424 ps/dB 是「全程带宽可利用」上限，真实可用口径 ≈ 424×0.915 ≈ 388 ps/dB。

## 关键数字 旧→新

- FoM：424 ps/dB（解析）→ 389 ps/dB（器件级真实链）/ 384 ps/dB（3 dB 预算应用级，含 R 惩罚）
- 3 dB 预算摆幅/窗口：1.274 ns / 0.191 m → 1.167 ns / 0.175 m（−8.4%）
- spike 形状：0.10 ps 高斯 → 0.146 ps FWHM 实测压缩脉冲（含旁瓣）；链结论不变

## 遗留问题

- 器件级若把 R<1（平台均值 R=0.990，0.043 dB 一次性反射惩罚）与 0.008 dB 传播损耗并列，
  FoM 会被压到 62 ps/dB——这是「固定损耗 vs 随长度缩放损耗」口径问题，不是物理恶化；
  在应用尺度（3 dB 预算）该惩罚占比 <1.5%。建议 FoM 定义保持传播损耗口径，R 惩罚单列。
- 真实脉冲旁瓣使 |t|<0.3 ps 内能量仅占 4%（高斯 ≈100%）；本任务的三类场景间隔 0.6–1.0 ps
  下仍满分，但更密间隔场景的区分度未测——Stage 3 可补脉冲间隔扫描。
- 排障记录：重建脉冲时若把 fftshift 后的非单调时间轴喂给 np.interp 会静默得全零
  （已在本脚本注释中固化，勿踩）。
