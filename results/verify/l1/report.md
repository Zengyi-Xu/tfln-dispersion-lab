- FDTD 脚本：`verify/l1_fdtd_rerun.py`（复用 `lumerical/run_scan_2d.py` 模型，仅 dx 10→5 nm、
  窗口 1515–1625nm/121pt → 1500–1640nm/281pt；dy=20nm 不变）
- 分析脚本：`verify/l1_analyze.py`（import `verify/v2_reextract_a1a2.py` 的冻结函数，口径与 V2 逐一致）

- 耗时：ref+w1470+w1520 三个细网格运行共 ~62 min（6 进程×2 线程）

## 结论原文

- C7 复核值：dλ_B/dw = 40.65±0.53 nm/µm（R²=0.999，midgap 法，阈值 0.1–0.9 稳健 39.9–40.9）
- C8 复核值：κ ≈ 607/cm（五条 w 谱 606–608/cm，对条宽不敏感）

## 复核结果：**支持**（两项验收均通过，数值假象排除）

| 量 | 基准（双机复核，dx=10nm） | 细网格重跑（dx=5nm，281pt 宽窗） | 判定 |
|---|---|---|---|
| n_g（ref 重算） | 2.10457 | 2.10365（−0.044%） | ✓ 收敛 |
| λB midgap w1470 | 1566.608 nm | 1566.368 nm（−0.24 nm） | 见下 |
| λB midgap w1520 | 1568.679 nm | 1568.408 nm（−0.27 nm） | 见下 |
| dλB/dw（细网格两端点） | 40.65±0.53 | **40.79 nm/µm** | ✓ 在 [40.12, 41.18] 内 |
| dλB/dw 阈值扫描 0.1–0.9 | 39.9–40.9 | 40.76–40.90（更稳） | ✓ |
| κ w1470 / w1520 | 607 / 607 /cm | **607.5 / 607.0 /cm**（旧 n_g 口径；新 n_g 口径 607.3/606.7） | ✓ 在 606–608 ±3 内 |

- λB 绝对值有 −0.24/−0.27 nm 的**共模**偏移（两点位移同向同量），判断为 dx=10nm 网格
  对 193.75 nm 半周期台阶的 staircasing 系统误差；细网格值更准。共模偏移不改变斜率与 κ，
  对应用无影响（±10nm 条宽容差对应 ±0.41nm λB 偏移的口径不变）。
- 谱形（`l1_fine_grid.png`）：单一平底阻带、minT=0.001、n_runs=1（无多凹陷误判），
  细/粗网格谱几乎重合；宽窗口（1500–1640nm）确认阻带两侧无非物理结构。

## 关键数字 旧→新

- dλB/dw：40.65±0.53（旧网格复核值）→ 40.79（细网格两端点）/ 40.76–40.90（阈值扫描）——**收敛**
- κ(w1470)：607 → 607.5/cm；κ(w1520)：607 → 607.0/cm ——**收敛**
- λB 绝对位置：细网格系统性 −0.25 nm（共模；仅影响绝对定标，不影响任何已入库结论）

## 建议措辞

- C7/C8 维持 V2 复核值不变：**dλB/dw ≈ 41 nm/µm、κ ≈ 607/cm 获网格收敛性确认**
  （可在报告/申请书中注明「经 dx=10→5nm 网格收敛验证」）。

## 遗留问题

- 混合 5 点拟合（新 w1470/w1520 + 旧 w1480/1500/1530）得 41.33 nm/µm，略出 ±0.53 区间
  （+0.68）。原因是混用两种网格精度的点（旧三点带 +0.25nm 共模偏移），**不是物理分歧**；
  纯细网格两端点斜率（40.79）才是收敛性判据。若需 5 点全细网格拟合，补跑
  w1480/w1500/w1530_fine（各 ~25 min）即可，但现有证据已满足验收。
- λB 绝对定标若要消掉 −0.25nm 共模偏移，应以细网格值为准更新；当前没有任何已入库结论
  依赖 λB 的绝对值到 0.25nm 精度，故未改动旧数据。
